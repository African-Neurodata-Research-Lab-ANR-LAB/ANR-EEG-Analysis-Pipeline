# ANR EEG Analysis Pipeline v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a tested, installable MNE-powered ANR EEG package whose primary input is ANR Muse Recorder CSV and which can be installed directly from the ANR GitHub repository into Google Colab.

**Architecture:** `anr_eeg` wraps MNE-Python with a small ANR-specific API. Import converts ANR Muse CSV into standard MNE Raw objects; all later modules operate on MNE objects; exports and reports create reproducible ANR research outputs without duplicating MNE internals.

**Tech Stack:** Python 3.11+, MNE-Python 1.12.x, MNE-BIDS 0.19.x, NumPy, pandas, SciPy, Matplotlib, pytest, Jupyter/Google Colab.

**Spec:** `docs/superpowers/specs/2026-08-25-anr-eeg-v1-design.md`

## Global Constraints

- Python `>=3.11`.
- `mne>=1.12,<2` and `mne-bids>=0.19,<1`.
- ANR Muse CSV is the first-class input format.
- Required EEG columns: `TP9_uV`, `AF7_uV`, `AF8_uV`, `TP10_uV`.
- CSV EEG values are µV and must be converted to volts before MNE construction.
- Automatic ICA, ERP, time-frequency, connectivity, and ML are out of v1 scope.
- No participant data is committed.
- QC/report language remains technical and non-diagnostic.
- GitHub is the source of truth; Colab installs from GitHub.
