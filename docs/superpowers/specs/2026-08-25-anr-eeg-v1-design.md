# ANR EEG Analysis Pipeline v1.0 Design

**Date:** 2026-08-25  
**Project:** African NeuroData Research Lab (ANR)  
**Repository:** `ANR-EEG-Analysis-Pipeline`  
**Package:** `anr-eeg`

## Purpose

ANR-EEG-Analysis-Pipeline v1.0 is a reproducible EEG research workflow built on top of MNE-Python. The first-class input is the CSV generated by the ANR Muse EEG Recorder. Standard MNE-compatible formats remain secondary inputs.

ANR does not fork or copy MNE-Python. MNE supplies the scientific primitives; ANR supplies a validated workflow, ANR Muse compatibility, quality-control summaries, standardized outputs, reports, and a Google Colab entry point.

## v1 scope

- ANR Muse CSV import.
- Automatic detection of `TP9_uV`, `AF7_uV`, `AF8_uV`, `TP10_uV`.
- Timestamp validation and 256 Hz Muse support.
- µV-to-V conversion before MNE `RawArray` creation.
- ANR event-marker import as MNE annotations.
- Secondary import for EDF/BDF, FIF, BrainVision, and BIDS EEG.
- Technical recording QC.
- Configurable 50/60 Hz notch filtering.
- Configurable 1–40 Hz band-pass filtering.
- Optional re-referencing.
- Welch PSD.
- Relative delta/theta/alpha/beta band power.
- Clean FIF export, QC JSON, band-power CSV, summary JSON.
- MNE HTML research report.
- Functional Google Colab notebook that installs from GitHub.
- Automated tests and GitHub CI.

Out of scope for v1: automatic ICA, ERP, time-frequency, connectivity, decoding, and ML.

## Public API

```python
from anr_eeg import (
    load_eeg,
    run_qc,
    preprocess,
    compute_psd,
    compute_band_power,
    export_results,
    make_report,
)
```

### `load_eeg`

```python
load_eeg(path, *, sfreq=None, format=None, bids_path=None)
```

Returns an MNE Raw object. For ANR Muse CSV it validates channels, estimates/validates sampling rate, converts µV to V, creates `RawArray`, and attaches ANR event markers as annotations.

Required Muse columns:

```text
TP9_uV
AF7_uV
AF8_uV
TP10_uV
```

At least one time source is required for automatic sampling-rate estimation:

```text
timestamp_ms
iso_time
```

`event_marker` is optional.

Adjacent rows containing the same non-empty marker are collapsed into one event annotation.

### `run_qc`

```python
run_qc(raw) -> dict
```

Returns a JSON-serializable technical acquisition summary: channels, sample rate, duration, sample count, non-finite counts, flat-channel flags, SD and peak-to-peak per channel, annotation count, and overall `pass` / `review` / `fail` status.

QC is not clinical interpretation.

### `preprocess`

```python
preprocess(raw, *, l_freq=1.0, h_freq=40.0, notch=50.0, reference=None)
```

Copies input, optionally notch-filters, band-pass filters, then optionally re-references. `reference=None` preserves the original reference.

### Spectral analysis

```python
compute_psd(raw, *, fmin=1.0, fmax=40.0)
compute_band_power(raw)
```

Bands:

- delta: 1–4 Hz
- theta: 4–8 Hz
- alpha: 8–13 Hz
- beta: 13–30 Hz

Band power is normalized per channel over total 1–30 Hz power.

### Export

```python
export_results(raw, qc, band_power, output_dir, *, prefix="anr_eeg")
```

Outputs:

- `<prefix>_clean_raw.fif`
- `<prefix>_qc.json`
- `<prefix>_band_power.csv`
- `<prefix>_summary.json`

### HTML report

```python
make_report(raw, qc, band_power, output_path, *, title="ANR EEG Analysis Report")
```

MNE Report contains metadata, QC, PSD figure, relative band-power table, annotation summary, and research-use statement.

## Google Colab architecture

GitHub is the single source of truth. Public installation:

```python
!pip install "git+https://github.com/African-Neurodata-Research-Lab-ANR-LAB/ANR-EEG-Analysis-Pipeline.git"
```

Then:

```python
from anr_eeg import load_eeg, run_qc, preprocess, compute_band_power
raw = load_eeg("/content/recording.csv")
qc = run_qc(raw)
clean = preprocess(raw)
bands = compute_band_power(clean)
```

If the repository remains private during development, anonymous pip installation cannot work. The Colab notebook will document use of a GitHub token stored in Colab Secrets; no token is embedded in code, notebooks, outputs, or logs.

## Error handling

Hard errors:

- missing required Muse channels
- unreadable files
- unsupported explicit format
- malformed timestamps
- invalid sampling rate
- analysis requested on recordings too short to support it
- output path creation failure

Warnings:

- no markers present
- unusual but usable sample rate
- flat/high-amplitude channel conditions
- acquisition characteristics requiring review

## Testing

Tests use synthetic EEG generated at runtime; no participant data is committed.

Required coverage:

- ANR Muse CSV import and µV→V scaling
- sampling-rate estimation
- missing-channel failure
- marker deduplication and timing
- QC status logic
- preprocessing input immutability
- PSD bounds
- relative band-power normalization
- parseable exports
- HTML report generation
- full end-to-end workflow

## Data governance

`.gitignore` excludes human EEG recordings and common neurophysiology file formats from accidental commits. Test fixtures are synthetic and generated in temporary directories.

## Research boundary

The pipeline is for research analysis. QC flags, spectral features, plots, and reports do not diagnose seizures, epilepsy, or neurological disease and do not replace clinical EEG interpretation.
